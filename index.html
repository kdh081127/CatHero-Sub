🧮 덱 구성 추천 결과

기본 공격력 + 장착한 동료·스킬의 보유효과, 스킬 효과 수치를 바탕으로 예상 딜량을 계산합니다. (효과 문구에서 숫자를 자동으로 읽어오는 방식이라 근사치입니다.)

계산 방식
  • 기본 공격력(1~10,000)에 장착한 동료·스킬의 "보유 효과" 중 공격력 증폭(%) 값을 전부 합산해 최종 공격력을 구합니다.
  • 장착한 스킬마다 "효과" 문구에서 가장 큰 퍼센트(%) 수치를 찾아 최종 공격력 × 그 수치로 예상 피해량을 계산합니다.
  • 스킬 6개의 예상 피해량을 모두 더한 값을 총 예상 딜량으로 보여줍니다.
  • 성급/등급은 12성 · 25성 · 10각 기준점만 두고 비교 (13~24성처럼 세밀한 구간별 계산은 생략)

💎 냥혼석 세공

증가능력1 / 증가능력2 / 감소능력1, 매 칸마다 성공·실패를 기록하면 확률이 자동으로 갱신되고, 레벨 달성 확률도 실시간으로 계산됩니다.

세공 확률 75%
세공 규칙
  • 각 옵션(증가능력1 · 증가능력2 · 감소능력1)마다 10번의 기회가 주어집니다.
  • 세공 확률은 3개 옵션이 전부 공유합니다 — 어느 옵션에서 성공하든 전체 확률이 -10%p, 실패하면 +10%p (예: 증가능력1 성공 65% → 증가능력2 성공 55% → 다음 실패 시 다시 65%).
  • 세공 확률은 75%에서 시작하며, 최저 25% · 최고 75%로 고정됩니다.
  • 레벨 1은 4번 성공, 레벨 2는 7번 성공, 레벨 3은 9번 성공 시 달성됩니다 (옵션별로 각자 카운트).
  • 감소능력1은 어떤 냥혼석이든 고정적으로 존재하는 옵션입니다.
